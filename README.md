# 🏅 Athletes Events Data Analysis

A complete data analysis project focused on Olympic Games historical data, using **SQL, Python, and Power BI** to transform raw data into actionable insights.

---

## 📊 Project Overview

This project analyzes a historical dataset of the modern Olympic Games (1896–2016), containing over **270,000 athlete-event records**, including attributes such as age, gender, country, sport, and medals.

The goal is to demonstrate an end-to-end data workflow:

➡️ **Data extraction and transformation with SQL**
➡️ **Exploratory data analysis (EDA) with Python**
➡️ **Data visualization and storytelling with Power BI**

---

## 📂 Dataset

The dataset used in this project can be found here:

🔗 **[[Kaggle – 120 Years of Olympic History: Athletes and Results](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)]**

---

## 🧠 Business Questions

* Which countries dominate specific sports?
* How has female participation evolved over time?
* Are there physical patterns (height, weight, age) associated with performance?
* How has medal distribution changed across decades?

---

## 🛠️ Technologies Used

* **SQL (PostgreSQL / SQLite)** → Data extraction and transformation
* **Python (Pandas, NumPy, Matplotlib)** → Exploratory Data Analysis
* **Jupyter Notebook** → Data exploration and validation
* **Power BI** → Interactive dashboards and KPI visualization

## 🔄 Data Pipeline

### 1. 🧱 Data Modeling & Transformation (SQL)

* Creation of analytical queries and datasets

### 2. 🔍 Exploratory Data Analysis (Python)

* Pattern and trend identification
* Statistical analysis of key variables
* Data visualization for hypothesis validation

### 3. 📊 Data Visualization (Power BI)

* Development of interactive dashboards
* Creation of business-oriented KPIs
* Dynamic filters (gender, sport, time period)

---

## 📈 Key Metrics (KPIs)

* 🏓 Total number of athletes
* 🥇 Total medals by game edition
* 👩🏻 Female athletes participation 
* 🏃 Athlete and Medals distribution by sport
* ⚖️ Average physical attributes (height, weight, age)

---

## 💡 Key Insights

* Identification of consistently high-performing countries
* Significant growth in female participation over time
* Medal concentration varies by sport and region
* Physical attributes differ depending on sport type
